VU meters (dBFS)

LED ladder = peak level in 3 dB steps (green up to -18, yellow up to -6, red above), top LED = clip (tap a meter to clear), white-bright step = peak hold, blue bar = RMS. Input meters read after input gain, before mute. MUTE under each meter works on that channel only; output MUTE matches the button in the channel panel.

Input source

Pick a device. Needs HTTPS and microphone permission. Echo cancel, noise suppression and AGC are off.
USB sound card on Android: connect it with a USB OTG cable, press Allow / refresh, then choose it in the list. If it is missing, unplug and replug, then refresh. It only works if Android exposes the card to Chrome as an audio input. Monitor ON passes the input live through the matrix and DSP to the output, like input monitoring in a DAW.
Feedback risk: live mic + speaker can howl. Use headphones, or press Monitor OFF, or turn gains down. Latency depends on the device and Android; see the status line.

Real-time analyzer, 1/3 octave, 20 Hz - 20 kHz

 
One analyzer each for IN L, IN R (after input gain), OUT CH 1 and OUT CH 2 (final output). FFT 8192, uncalibrated dB relative to full scale, white tick = peak hold.




Signal flow: Source → IN L / IN R (gain) → routing matrix → per output: Crossover (HPF → LPF) → EQ (3 bands) → Compressor → Makeup → Output gain/mute/polarity → Delay → Meter → OUT CH 1 (device left) or OUT CH 2 (device right). The outputs share no nodes after the matrix; each has its own filters, compressor (native node, no stereo link), delay and analyzers. The isolation test measures routing in your browser; I have not run it myself.

Compressor display: the curve is the ideal static curve of your settings; the dot (input peak vs output peak) and the IN/GR/OUT bars are measured from the audio. Delay: 0 to 3000 ms per output, entered as ms, m or ft (speed of sound adjustable).
Limits: Crossover = Butterworth and Bessel 6-48 dB/oct, Linkwitz-Riley 12/24/36/48 dB/oct (Bessel is normalized to -3 dB at the cutoff). Compressor = native node (Chrome adds auto makeup and ~6 ms look-ahead). Changing crossover settings rebuilds that output's filters and may click. Polarity is not time alignment. YouTube/tab audio cannot be captured on Android. The browser may deliver only 2 input channels from a multichannel sound card, and the output is a 2-channel device.
